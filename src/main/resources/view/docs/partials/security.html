Security & Authentication

The authentication system is based on UserDetailsService, an abstraction that lets you organize your User model however you want. All auth helpers are available via the static Auth class — no inheritance required.

1. Create your UserDetailsService
@UserDetailsServiceImpl
public class AppUserDetailsService implements UserDetailsService {

    private final UserRepository userRepository;

    public AppUserDetailsService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    @Override
    public UserDetails loadByUsername(String username) {
        return userRepository.findByUsername(username);
    }

    @Override
    public UserDetails loadById(Object id) {
        return userRepository.findById(id);
    }
}
2. Login and logout
@Controller
public class AuthController extends BaseController {

    @POST("/login")
    @CsrfProtect
    public String login(Request req, Response res) {
        try {
            if (Auth.login(req.queryParams("username"), req.queryParams("password"), req)) {
                String redirect = Auth.getRedirectAfterLogin(req, "/dashboard");
                res.redirect(redirect);
                halt();
            }
            return redirectWithFlash(req, res, "error", "Invalid credentials.", "/login");
        } catch (LoginLockedException e) {
            return redirectWithFlash(req, res, "error", e.getMessage(), "/login");
        }
    }

    @GET("/logout")
    @RequireLogin
    public String logout(Request req, Response res) {
        Auth.logout(req.session());
        res.redirect("/login");
        halt();
        return null;
    }
}
Auth utility class
// Login — includes session fixation protection and brute force check
Auth.login(username, password, req)

// Logout
Auth.logout(req.session())

// Checks
Auth.isLogged(req)              // Is the user authenticated?
Auth.hasRole(req, "ADMIN")      // Does the user have this role?

// User retrieval — cached per request, no redundant DB calls
Auth.user(req)                  // Get the authenticated UserDetails

// Password
Auth.hashPassword("secret")
Auth.checkPassword("secret", hash)

// Redirect after login
Auth.getRedirectAfterLogin(req, "/dashboard")
Note: BaseController still exposes the same methods as delegates — existing code is not broken.
Protecting routes with @RequireLogin

Use @RequireLogin to protect a route or an entire controller. Unauthenticated users are redirected to /login, and the original URL is restored after authentication. 

// Method level
@GET("/dashboard")
@RequireLogin
public String dashboard(Request req, Response res) { ... }

// Class level — all routes in this controller are protected
@Controller
@RequireLogin
public class DashboardController extends BaseController {

    @GET("/dashboard")
    public String index(Request req, Response res) { ... }

    @GET("/settings")
    public String settings(Request req, Response res) { ... }
}
Role-based protection with @HasRole

Use @HasRole to restrict access to a specific role. It can be applied at method level or class level. Method-level annotations take precedence. 

// All routes in this controller require the ADMIN role
@Controller
@HasRole("ADMIN")
public class AdminController extends BaseController {

    @GET("/admin")
    public String index(Request req, Response res) { ... }

    // Override class-level — requires SUPERADMIN instead
    @GET("/admin/users")
    @HasRole("SUPERADMIN")
    public String users(Request req, Response res) { ... }
}
Injecting the current user with @CurrentUser

Add a parameter annotated with @CurrentUser to receive the authenticated user directly in your controller method. The user is resolved from the per-request cache — no extra DB call. 

@GET("/dashboard")
@RequireLogin
public String dashboard(Request req, Response res, @CurrentUser User user) {
    return render("dashboard.html", Map.of("user", user));
}

// Works with custom UserDetails implementations
@GET("/profile")
@RequireLogin
public String profile(Request req, Response res, @CurrentUser AppUserDetails user) {
    return render("profile.html", Map.of("user", user, "email", user.getEmail()));
}
Custom UserDetails
// 1. Extend the UserDetails interface
public interface AppUserDetails extends UserDetails {
    String getEmail();
    String getUUID();
}

// 2. Implement it in your User model
@Table("users")
public class User extends Model implements AppUserDetails {
    public Object getId()       { return getLong("id"); }
    public String getUsername() { return getString("username"); }
    public String getPassword() { return getString("password"); }
    public String getRole()     { return getString("role"); }
    public String getEmail()    { return getString("email"); }
    public String getUUID()     { return getString("uuid"); }
}

// 3. Use directly in controllers
@GET("/profile")
@RequireLogin
public String profile(Request req, Response res, @CurrentUser AppUserDetails user) {
    String email = user.getEmail();  // ✅ Available
    return render("profile.html", Map.of("user", user));
}
Bearer token authentication (API)

For stateless API routes, use Bearer token authentication instead of sessions. Implement TokenResolver to validate tokens and resolve users.

1. Implement TokenResolver
@TokenResolverImpl
public class AppTokenResolver implements TokenResolver {
    @Override
    public UserDetails resolve(String token) {
        ApiToken t = ApiToken.findFirst("token = ?", token);
        if (t == null || t.isExpired()) return null;
        return User.findById(t.getLong("user_id"));
    }
}
2. Mark your controller as API
@Controller
@ApiController
public class UserApiController extends BaseController {

    @GET("/api/users")
    @RequireLogin
    public String index(Request req, Response res, @CurrentUser UserDetails user) {
        return json(map("users", userRepository.findAll()));
    }
}
3. Or protect a single route with @Bearer
@GET("/api/me")
@Bearer
public String me(Request req, Response res, @CurrentUser UserDetails user) {
    return json(map("user", user));
}
On authentication failure, API routes return JSON instead of redirecting: { "error": "Unauthorized" } (401) or { "error": "Forbidden" } (403).
Brute force protection

Auth.login() automatically enforces rate limiting per IP and per username. After 5 consecutive failed attempts, the IP and username are locked out for 15 minutes. 

try {
    if (Auth.login(username, password, req)) {
        res.redirect("/dashboard");
        halt();
    }
    return redirectWithFlash(req, res, "error", "Invalid credentials.", "/login");
} catch (LoginLockedException e) {
    // e.getMessage() → "Too many failed attempts. Try again in 847 seconds."
    return redirectWithFlash(req, res, "error", e.getMessage(), "/login");
}
Counters reset automatically on successful login. Lockouts are tracked independently per IP and per username.
💡 Tips
  • The @UserDetailsServiceImpl annotation allows the framework to automatically detect your implementation — no manual configuration needed.
  • @RequireLogin replaces the old @HasRole("DEFAULT") pattern.
  • Auth.user(req) is cached per request — calling it multiple times in the same request cycle does not trigger additional DB queries.
