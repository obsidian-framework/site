Observers

Observers let you hook into the model lifecycle without cluttering your model class. Each hook can optionally cancel the operation by returning false.

Available hooks
Method When Cancellable
saving(model) Before any save (insert or update) ✓ return false
saved(model) After any save (insert or update) —
creating(model) Before insert ✓ return false
created(model) After insert —
updating(model) Before update ✓ return false
updated(model) After update —
deleting(model) Before delete ✓ return false
deleted(model) After delete —
restoring(model) Before soft-delete restore ✓ return false
restored(model) After soft-delete restore —

Override only the methods you need — all hooks are no-ops by default.

Create an observer

Extend ModelObserver<T> and override the hooks you need.

public class ArticleObserver extends ModelObserver<Article> {

    @Override
    public boolean creating(Article article) {
        article.set("slug", slugify(article.getString("title")));
        return true;  // return false to cancel the insert
    }

    @Override
    public void created(Article article) {
        // Send notification, update search index, etc.
    }

    @Override
    public boolean updating(Article article) {
        // Recompute slug only if title changed
        if (article.isDirty("title")) {
            article.set("slug", slugify(article.getString("title")));
        }
        return true;
    }

    @Override
    public boolean deleting(Article article) {
        // Block deletion of published articles
        if (article.getInteger("status") == 1) {
            return false;  // cancels the delete
        }
        return true;
    }

    @Override
    public void deleted(Article article) {
        // Clean up related data
    }
}
Register in the model

Override observer() in your model to attach an observer.

@Table("articles")
public class Article extends Model {

    @Override
    protected ModelObserver<Article> observer() {
        return new ArticleObserver();
    }
}
Cancelling operations

Any before hook can abort the operation by returning false. When cancelled, save() or delete() returns false as well — nothing is written to the database.

public class UserObserver extends ModelObserver<User> {

    @Override
    public boolean saving(User user) {
        // Validate before any save
        if (user.getString("email") == null) {
            return false;  // aborts both insert and update
        }
        return true;
    }
}

// In a controller / service:
boolean saved = user.save();  // false if the observer cancelled it
💡

Hook call order for a save: saving → creating or updating → write to DB → created or updated → saved.
